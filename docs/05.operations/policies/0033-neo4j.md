# Neo4j Operations Policy

## Overview

이 정책은 root-active `OPTIONAL` Neo4j 운영 기준을 정의한다. 기준은 [Neo4j Compose 구현](../../../infra/04-data/neo4j/docker-compose.yml)의 단일 Community service, exact `graph` profile, `edge_net`, `neo4j_password` Docker Secret, secret-aware entrypoint와 Traefik Browser route다.

## Policy Scope

- `infra/04-data/neo4j/docker-compose.yml`
- `infra/04-data/neo4j/scripts/neo4j-entrypoint-with-secrets.sh`
- `neo4j` service와 `neo4j-data` volume
- `neo4j_password` Docker Secret과 `/run/secrets/neo4j_password` mount
- Neo4j Browser용 Traefik route `neo4j.${DEFAULT_URL}`
- `docs/05.operations` 아래에 연결된 guide와 runbook

## Controls

- **Required**: 문서는 Neo4j를 cluster나 Enterprise 배포가 아니라, exact `graph` profile로 선택되는 단일 Community service로 설명해야 한다.
- **Required**: 인증 가이드는 `neo4j_password` Docker Secret과 secret-aware entrypoint를 참조해야 하며 secret 값을 문서나 evidence에 절대 복사해서는 안 된다.
- **Required**: 공개 접근 가이드는 선언된 HTTP Browser route만 설명해야 한다. 공개 Bolt 라우팅에는 별도의 gateway 변경과 문서 갱신이 필요하다.
- **Required**: 메모리 제어는 compose 값과 일치해야 한다: heap initial `128M`, heap max `256M`, pagecache `128M`.
- **Required**: 백업 세트는 Community-compatible offline `neo4j-admin database dump`를 사용하며, database name, engine version, schema/index/constraint inventory, checksum, retention, restore evidence를 기록한다. credential은 별도로 관리한다.
- **Required**: Restore rehearsal은 새로운 isolated compatible Community target에 로드하고, database availability, constraints/indexes, counts, representative Cypher를 검증하며, 실패 시 target을 보존하고 정확한 소유 artifact의 삭제는 별도 승인한다.
- **Required**: online backup이나 cluster recovery는 주장할 수 없다. 이 상위 기능은 edition/topology에 의존하기 때문이다. Upgrade/removal에는 restore-tested dump와 capacity review가 필요하다.
- **Allowed**: read-only `cypher-shell RETURN 1`, compose config rendering, service logs, evidence 수집을 위한 `docker compose ps`.
- **Allowed**: image tag, profile, route, healthcheck, secret, volume 설명을 compose와 일치시키는 문서 전용 수정.
- **Disallowed**: 별도 승인 없는 password rotation이나 data mutation; tracked volume에 대한 in-place load와 존재하지 않는 Enterprise online-backup command도 금지한다.
- **Disallowed**: compose가 선언하지 않는 한 APOC/plugin mount나 public Bolt/TCP router가 활성 상태라고 주장하는 행위.

### Accountable lifecycle boundary

적용 identity: `neo4j`. 문서의 정적 검증과 runtime 운영 승인을 분리한다. @buenhyden이 named consumer·target·중단 영향·보존 기간과 예외를 소유한다. service image/profile/port/secret/mount, DDL·init, capacity 또는 backup 범위 변경 시 이 Policy와 linked Guide/Runbook을 함께 검토한다. engine secret/certificate는 이 subject의 credential 계약을, 앱 인증 연동은 적용되는 [POL-0079](0079-application-auth-integration.md)를, source 반영·재기동은 [POL-0006](0006-infrastructure-optimization-governance.md#source-and-lifecycle-boundary), 보존·삭제는 [POL-0021](0021-backup-and-restore.md)의 적용 통제를 따른다. exporter와 stateless job 자체에는 database restore가 없지만 설정·credential와 그 작업이 변경하는 upstream state는 제외되지 않는다. 소유 artifact·복구 지점·expiry가 불명확하면 삭제/재생성을 중단한다. 기존 Exceptions 외의 새 예외는 승인된 것으로 간주하지 않는다.
