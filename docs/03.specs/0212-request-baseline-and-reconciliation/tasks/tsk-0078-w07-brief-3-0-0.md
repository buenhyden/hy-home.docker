## Execution Log

### Work Performed

#### Design before implementation

The current prompt router and resume hooks supply context. Add a standard
library brief check to their existing covered edit path. Use the observed
session request digest and revision, canonical workspace and Git baseline.
Persist only the minimal private hook state needed for consistency. The
planner authors the goal, non-goals, assumptions, acceptance, questions,
risk, allowed actions and checks as distinct fields. Preparing a brief
does not send another user question for a clear request.

Register the brief on the current session after read-only discovery. Check
absolute or relative edit targets as exact repository paths on enrolled
sessions. Require the explicit check before preparing a delegated write.
Keep unrelated read-only work outside the check. Recheck or invalidate the
record on a new request and on a resumed or compacted session. A material
question holds only its affected action. Hook refusal uses the supported
PreToolUse denial shape. The brief provides no authority and cannot
replace a user's authorization or native permission.

Avoid generic shell parsing, unconditional per-tool approval and shared
approval files. Native calls with unavailable scope stay coverage gaps.
Recover by reverting the bounded hook and planner changes together.
Test direct and literal nested edits, scope, request corrections,
questions, resume and compact, failed inputs, and no authority promotion.

#### Implementation and observation

Read D08, D03 and the supplied research entries S03, S06, S07, S10 and
S20–S23, plus the Docker binding profile, decisions and repository/PR
observations. Reused the accepted W01 implementation, native event
registrations, path decoder and independent approval policy. The actual
installed lookup reported Codex CLI 0.169.0 and Claude Code 2.1.325
through their `--version` commands. The GitHub PR lookup returned 1047
and 1048 open. No remote work was needed for local source verification.

The shared hook observes the native request without storing the prompt.
The standard-library CLI checks the current request revision, exact paths,
Git HEAD and declared material file digests. File-backed Task state changes
use the same exact path check. A material question holds its affected action.
An explicit handoff check requires both edit and dispatch scope for each
path. A null or unrelated reference can describe a plan but leaves mutation
blocked. An older reference can be reconsidered only within its previous
scope and identical material inputs after checking the actual authority.
No approval or reusable raw brief prose is written to the session state.

The independent revision marker invalidates old bindings before a competing
writer takes the snapshot lock. Consecutive compaction hooks can retain the
already bounded reference for reconsideration while leaving the brief
unbound. Regression inputs also reject added material files on reuse,
partially missing enrollment state and a repository Git config monitor.

Seven local dispatcher samples per build and prompt produced median before
and after values of 47.73 and 83.46 ms for the Claude-shaped
`UserPromptSubmit` and 51.36 and 86.04 ms for the Codex-shaped event.
The Claude-shaped recognized edit in an unenrolled session was 91.27 and
123.23 ms. These include shell and Python process startup and local load.
They do not measure native model feedback or user confirmation time.
