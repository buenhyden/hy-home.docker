### Work Performed

#### Design before implementation

The heading reader can mistake lines inside an HTML comment for canonical
headings. Use the installed Markdown parser to recognize structural
headings and keep the current ATX title convention. Keep the current role
titles where their guidance, sections and tables serve the design purpose.
An across-the-corpus rename or a generic H3 in every section would add
migration work without a reader requirement.

Missing or duplicate real sections must be reported at their existing
validation boundary. Preserve native file
grammar, publication commands, authored relationships and the installed
language bindings. The change can be corrected by reverting its source
unit and restoring the matching schema and readers. Exercise the failing
cases first, then run the role/Registry suite and the affected corpus checks.
