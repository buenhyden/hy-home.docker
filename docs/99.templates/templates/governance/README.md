# Governance Templates

## Overview

Stage 00 governance profiles are machine-owned by `docs/99.templates/registry.json`.
Policies, roles, provider adapters, and skills are maintained in their canonical
Stage 00 directories; no parallel handoff document is created.

## Audience

Maintainers who author Stage 00 governance or regenerate provider projections.

## Scope

- Profile selection and required frontmatter come from the Stage 99 registry.
- Canonical human content lives in Stage 00.
- Provider projections are generated by the registered renderer.

## Structure

This directory intentionally has no copy template. Governance changes begin from
the closest canonical document and preserve its registered profile.

## How to Work in This Area

1. Select the profile from the Stage 99 registry.
2. Edit only the canonical Stage 00 source.
3. Run the Stage 00 contract validator.
4. Regenerate registered provider projections and record evidence in the Task.
